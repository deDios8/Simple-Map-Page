# Code style

Write code for a relatively new React/Expo programmer to read and maintain, not for maximum cleverness.

- Prefer plain, explicit code over clever one-liners or abstractions.
- Don't add new libraries or utilities unless the task genuinely needs one — check if it's already solvable with what's installed first.
- Avoid introducing patterns (HOCs, generics, custom hooks, config-driven abstractions) unless the task clearly calls for them.
- When there's a simple way and a fancy way to do something, choose the simple way, even if it's a little more verbose.
